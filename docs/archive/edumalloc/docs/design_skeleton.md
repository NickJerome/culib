## 设计公理（优先级从高到低）

1. **教学可理解性优先**：核心架构概念数最少化；每层一页纸讲清；快路径 < 40 行可通读。
2. **内存安全是默认属性**：结构性防御零开销常驻；主动防御默认开启（开销**按机制计**，
   不承诺百分比——历史上那个"≤5%"从未按该口径测过，已作废）；重型检测编译期或采样开启。
3. **低占用**：元数据 ≤0.3%；空闲页**在有新 slice 需求时** 1 秒内归还 OS（或由
   `ed_collect` 立即归还）；按需提交物理页。
4. **高性能**：快路径零锁零原子；跨线程 free 恰好一次**成功** CAS；**页级弹链** ≤10 条指令。

取舍序：**1 > 2 > 3 > 4**。这条序是仲裁规则，不是修辞——`docs/design.md` 里每一处
"为什么接受这个代价"最终都回溯到它。

## 总体架构

分层：`API → theap（tcache + 直达页 + 页队列）→ page（64 KiB，同尺寸块）→ arena（slice 位图）→ 地址窗口 / OS`

采用 mimalloc 的 page-centric 模型，而非 jemalloc 的 arena/bin 模型。关键取舍：

| 子系统 | 选择 | 一句话理由 |
|---|---|---|
| 并发分区 | mimalloc 的 page 所有权 | 一条不变式替代整套锁协议；**分片代替锁** |
| 线程缓存 | **两家之间**：tcache 最小形态，与直达页数组并存 | 本项目 free 路径背着 L0 常驻检查，删掉它 larson 低于 glibc |
| 小对象管理 | mimalloc 的页内三条空闲链 | 并发释放分流，释放侧无锁无位图扫描 |
| 跨线程释放 | mimalloc 的一次 CAS 压 `xthread_free` | 无归属查找、无锁竞争；**未采纳**释放驱动 reclaim |
| 线程退出 | mimalloc 的 abandon + 一处加强 | 遗弃代替迁移；v2 先 collect，全空页直接归还 slice |
| 尺寸分级 | mimalloc 纯位移公式 | 免建表；线性区按 16 字节取整（ABI 要求），与 jemalloc 量子殊途同归 |
| ptr→元数据映射 | **两家都不取**：单一地址窗口 + 平铺描述符数组 | 一次减法 + 一次移位 + 一次数组访问，连查表层都没有 |
| 大对象 | **统一**：全部从 arena 切连续 slice | huge 只是一个标志位，**不再有独立映射** |
| 元数据自举 | jemalloc 的 `base` bump 池思想 | 消除自举递归；元数据与用户数据物理分离 |
| 内存归还 | mimalloc 两态 + 到期 purge | 砍掉 muzzy 态与 decay 预测器；无后台线程 |
| 安全默认级别 | **超额**：L0 + tcache 校验常驻，L1 默认开启 | 两个参照系都把安全当可选配置，本项目当默认属性 |

从 jemalloc 继承的三条独立遗产：大对象溢出阈值（`ED_HUGE_THRESHOLD` 与
`oversize_threshold` 同值）、满页隔离（`ED_BIN_FULL`）、释放安全检查
（`large_dalloc_safety_checks` 思想，进 L0）。

**四处"两家都不照抄"的格子**共享同一句话——*一个成熟实现的结论，成立在它自己的前提上*。
四格的完整推理与实测在 `docs/design.md` §13.1.1。

## 概念索引

概念名 → 一句话定义 → 数字/字段在哪。**本表不复制数字**，只负责让你知道去哪查。

### 地址空间

| 概念 | 一句话 | 事实源 |
|---|---|---|
| **地址窗口** window | 进程启动时一次性保留的连续虚拟区，所有 arena 从中顺序切分；只增不减。**进程可用堆的硬上限** | `SPEC.md` §1、§3.1 |
| **平铺描述符数组** | 与窗口等长的第二片保留区，slice i 的描述符恒为 `ed_desc_base[i]`；按 arena 粒度提交，提交后为零 | `SPEC.md` §3.1 |
| **slice** | arena 位图管理的最小粒度，**也是提交粒度**（v1 的 16 KiB 细分已删除） | `SPEC.md` §1 |
| **arena** | 窗口内切下的一段连续 slice，四张位图 + 一把锁 + abandoned 桶 | `SPEC.md` §3 |
| **CONT 续页项** | 多 slice 页的后续描述符，只存 `kind`/`cont_first`/`magic`，**不存 `slice_count`** | `SPEC.md` §3.1、`src/internal.h` |
| **`ed_ptr_page`** | free 第一步：一次减法 + 一次移位 + 一次数组访问，命中续页项则跳一次并做**三条复核** | `src/internal.h`（权威）、`SPEC.md` §3.1 |

**承重约束**（改之前必须读，不是风格偏好）：

- **三条复核缺一不可**。`ed_desc_clear` 只清首项 magic、续页项一律不清，所以读侧可能
  拿到陈旧 CONT 项。漏掉 `kind != CONT` 那条实测导致**两次分配返回重叠内存**。
  四格枚举表在 `src/internal.h` 的 `ed_ptr_page` 上方；另有**第四道守卫** `first >= idx`，
  它守的是越界读本身、不算三条复核之一。回归用例 `test_stale_cont_lookup`。
- **登记顺序不可交换**：`ed_desc_mark_cont` 写完全部续页项，才 `ed_page_publish` 点亮首项。

### 页

| 概念 | 一句话 | 事实源 |
|---|---|---|
| **page / `ed_page_t`** | 64 KiB 分配单元，描述符恰 128 字节（两条 cache line） | `SPEC.md` §3 |
| **block** | 页内等长切分的用户对象容器，块大小恒为 16 的倍数 | `SPEC.md` §2 |
| **bin** | 尺寸等级；编号 1–36，**1/3/5/7 闲置**（线性区取偶），实际可用 32 档 | `SPEC.md` §2 |
| **三条空闲链** | `free`（可分配，仅 owner）/ `local_free`（本线程延迟释放）/ `xthread_free`（他线程 CAS 压入，裸指针、**无所有权位**） | `SPEC.md` §3 |
| **`magic`** | L0 校验门槛，**也是唯一的发布点**（`ed_page_init` 先熄灭、写字段、最后显式 `ed_page_publish`） | `SPEC.md` §3 |
| **`flags`** | 五个互不重叠的位：`IN_FULL` / `HUGE` / `GUARDED` / `HAS_ALIGNED` / `PRIVATE`（`BARE` 已删除） | `SPEC.md` §1 |
| **retire 退休** | 页全空后的归还判定；**宽限只给本 bin 最后一页**，其余全空页立即归还 slice | `SPEC.md` §1、§4.6 |

**承重约束**：页级不变式 `used + |free| + |local_free| = capacity`——**没有
`-|xthread_free|`**（v1 设计稿在这里写错过）。ED_DEBUG 下 `ed_page_check_invariants`
是它的可执行形式，**不做抽样**（抽样会让它变质成"大概率相等"，而它要抓的正是低频偏差）。

### 线程与并发

| 概念 | 一句话 | 事实源 |
|---|---|---|
| **theap** | 线程本地堆：tcache + 直达页数组 + 每 bin 队列 + 满页队列 + 统计 | `SPEC.md` §3 |
| **tcache** | 线程本地小块缓存，单链 LIFO、按**字节预算**封顶、无 GC 纪元；块在其中时页视角仍算已分配 | `SPEC.md` §1 |
| **`pages_free_direct`** | 小 bin 的直达当前分配页，省掉"查队列"那一跳 | `SPEC.md` §1、§3 |
| **`ED_BIN_FULL`** | 满页隔离队列；**隔离即终点**，不做"超出即 abandon" | `SPEC.md` §1 |
| **abandon / reclaim** | 线程退出把仍有活块的页登记到 arena 的 abandoned 桶；**只有分配驱动 reclaim**，另有两条兜底 | `SPEC.md` §4.7 |
| **heartbeat** | 每线程单调计数，驱动退休宽限扫描（不参与随机源搅拌） | `SPEC.md` §3 |
| **`ed_heap_t`** | 一等私有堆，内嵌伪 theap + 堆级锁；其页打 `PRIVATE`、**不进 tcache** | `SPEC.md` §3 |

**承重约束（拿崩溃换来的，四平台实测见 `docs/decisions.md` 教训 A）**：

1. **线程退出钩子不能用 `thread_local` 对象的析构函数**，必须走 OS 层回调
   （`FlsAlloc` / `pthread_key_create`），theap 指针**作为参数传入**。
2. **钩子里不能从 TLS 读任何东西**；**但必须清 `ed_t_theap`**，且写成"读-比较-再写"
   `if (ed_t_theap == t) ed_t_theap = NULL;`。**不要加 `#if !defined(_WIN32)`**——
   MSVC 是最需要这次清零的平台。

### 安全层

| 层 | 一句话 | 事实源 |
|---|---|---|
| **L0** | 常驻结构性防御：元数据物理分离、无 header、size 溢出、窗口定界 + magic、续页项三条复核、`kind` 护栏、large 块首等值比较 | `SPEC.md` §5 |
| **tcache 校验** | 常驻、**不受 `SECURE` 影响**：驻留 guard（进程级随机 ^ 块地址）+ 链指针对齐 | `SPEC.md` §1、§5 |
| **L1** | 默认开启：空闲链 XOR 编码、页内洗牌、double-free 编码哨兵 | `SPEC.md` §5 |
| **L2** | 编译期 `--ed_debug=y`（**独立选项，不跟随 release/debug**）：首尾 canary、0xD0/0xDF 填充、内部指针校验、页不变式、泄漏报告 | `SPEC.md` §1、§5 |
| **L3** | 按请求字节倒数采样；**窗口内**多要一个 slice 置 PROT_NONE，对象贴守护页右对齐 | `SPEC.md` §5 |

**承重约束**：

- **头 canary 必须紧贴用户指针**（`user - 8`），因为块首找回对任何页内地址都给得出
  合法答案，它必须排在一个**只依赖用户指针**的校验之后。消融实测：挪回块首则三条注入
  用例全部漏检，而 `test_unit` 的两万八千条检查**照样全绿**——单元测试对这个位置完全无感
  （`docs/decisions.md` 教训 B）。
- **L3 右对齐起点必须按 `round_up(size,16)` 取整**，否则"返回值恒 16 字节对齐"会退化成
  "取决于 L3 有没有采到样"；`large_size` 同步记取整值。
- **"L1 编码哨兵能兜底内部指针"是假的**——哨兵只对已释放块有效（`docs/decisions.md` 教训 C）。

### 归还与免清零

| 概念 | 一句话 | 事实源 |
|---|---|---|
| **两态回收** | dirty（物理页仍持有，复用时**不清零**）→ decommitted；`HUGE`/`GUARDED` 页**不走**这个状态机，free 即 decommit | `SPEC.md` §4.8 |
| **`purge_expire`** | 到期时间戳；检查摊销进"要新 slice"那一支（不是每次 generic），为 0 时零开销；无后台线程 | `SPEC.md` §1、§4.8 |
| **免清零** | `slices_dirty` 是真值来源 → 分配出参 → **large calloc 跳过 memset**；小块那半条链**尚未接通** | `SPEC.md` §4.5 |

**承重约束**：免清零的失败模式是**静默的数据泄漏**，不是崩溃。所以这条路上每处记账都要
按"宁可多 memset"的方向取整（commit 失败回滚时保守地整段重新标脏）。两个前置条件
（非 ED_DEBUG、`guarded_sample_rate == 0`）都不是可有可无的。

### API、选项与预算

| 概念 | 一句话 | 事实源 |
|---|---|---|
| **公共 API** | 13 个符号，四族（标准 / 对齐 / heap / 诊断）；`ed_stats_get` 是 v2 唯一新增 | `include/edumalloc/edumalloc.h`（契约） |
| **`ed_stats_get`** | 机器可读状态快照；**不是原子快照**、会取 arena 锁、**不可在 fatal 路径或信号处理函数里调用** | 同上（头文件注释是权威） |
| **运行时选项** | 6 个 `EDUMALLOC_*`，启动解析一次、运行期只读；`PAGE_FULL_RETAIN` 已删除，`WINDOW_SIZE` 新增 | `SPEC.md` §6、`README.md` |
| **指令预算** | 页级弹链 ≤10 条 / 页级压链 ≤6 条 / 跨线程 free 一次成功 CAS。**口径是页级操作**，tcache 命中另按机制计 | `docs/design.md` §12.1.1 |
| **空间预算** | 元数据 ≤0.3%；另有两笔不同口径的账（窗口的虚拟保留、tcache 按线程数放大的滞留） | `docs/design.md` §12.2.1 |
| **碎片口径** | 指数区最坏约 20%（浪费/块）；**线性区单独按绝对字节记**（每块 ≤15 字节），两者不可混入同一个数字 | `SPEC.md` §2、`docs/design.md` §3.2 |
| **吞吐目标与实测** | larson ≥ glibc 1.5×（**达标 1.82×**）；单线程与 mimalloc ≤15%（**未达标，落后约 20%**） | `benchmark_results.md`、`docs/design.md` §12.3.2 |
| **测试矩阵** | 5 个可执行文件 × 六个构建组合；Linux 另加关 ASLR 复跑 | `SPEC.md` §9 |

## 渐进式教学路线（M0–M6）

| 里程碑 | 内容 | 估计代码量 | 可验证性质 | 教学主题 |
|---|---|---|---|---|
| M0 | bump 分配器（永不 free） | ~80 行 | 地址递增、对齐正确 | 为什么需要分配器 |
| M1 | 单线程：bins + page + free list | ~400 行 | 分配/释放正确性、碎片率测量 | 尺寸分级与空闲链 |
| M2 | 地址窗口 + 平铺描述符数组 + 无 header free + large | ~250 行 | free 正确路由、large 路径、**陈旧 CONT 项查表** | 元数据设计 |
| M3 | 线程本地 theap + xthread_free CAS | ~300 行 | 多线程压测无竞争错误 | 所有权模型 |
| M4 | abandon/reclaim + 线程退出钩子 | ~300 行 | churn 不泄漏；**并发宽度 churn**；退出钩子之后再分配 | 分片代替锁；TLS 生命周期 |
| M5 | arena slice 位图 + 到期 purge | ~400 行 | RSS 在负载下降 + collect 后回落 | 虚拟内存管理 |
| M6 | 安全层 L1–L3 + tcache 校验 | ~400 行 | double-free/UAF/内部指针注入被捕获 | 堆安全 |

**代码量口径**：上表是**教学路线的估计**（合计约 2100 行）——"按这条路自己写一遍，每步
大概要写多少"。**实际实现约 3750 行**（`src/` + `include/` + `src-override/`，测试约 1900 行、
基准约 800 行）；差额来自三工具链适配、可观测族、运行时不变式自检与 override 层。
**引用"约 2000 行"来描述本仓库是不准确的。**

两条"按常规写法测不出来"的验收条件是踩出来的，所以写进了里程碑而不是注释：M2 的
**陈旧续页项查表**（要主动构造一个曾当过首项、现被征用成别人续页项的描述符），
M4 的**并发宽度 churn**（关键变量是同时活着的线程数，不是总次数）。

## 引用规范

- 外部参照系行内引用格式：`（jemalloc, src/arena.c）`、`（mimalloc, src/page.c）`、
  `（jemalloc wiki §8）`。不使用 `[^N^]` 网络引文格式。
- 两份源码深度解析（`jemalloc.wiki.md`、`mimalloc.wiki.md`）是 v1 设计期的研究产出，
  不在本仓库内；行内引用保留是为了让"参照系怎么做"可被追溯。
- **本项目与参照系结论不同的地方，以本项目的实测依据为准**——参照系的结论成立在它
  自己的前提上（tcache、页元数据映射、大对象、满页上限四处）。
- **带数字的实测结论一律注明负载与出处**，并且要能**按原字符串 `grep` 回源码或
  `docs/decisions.md`**。追不到的数字应当被视为可疑——一个无法溯源的"实测值"比一句
  诚实的定性判断有害，因为读者没有办法分辨它们。
- **跨文档引用按名，不按编号。** 按号引用是文档漂移的放大器：任何一份文件重排章节，
  其余文件的引用就静默失效，而这种失效不会有任何检查报错。
